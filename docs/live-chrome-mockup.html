Fonts here are Google-hosted for the mock only. Real build self-hosts (venue wifi rule). Grain, scanlines and the roll bar are CSS; no assets.

Direction

What the reference actually is

Monochrome (true black, off-white, one grey), not neon. Frames are classic 1-bit OS windows: thick border, hard drop shadow, striped titlebar, square close box. Texture does the "lofi" work: scanlines, film grain, soft vignette, a slow roll bar. No gradients, no colour accent.

Why it fits this dashboard

  • Spec already calls for six OS-style windows; this is the same idea in 1-bit.
  • Black & white reads from across a room on a TV better than yellow-on-navy.
  • "Current segment" becomes inverted (white block, black text). Stronger than a colour highlight, and zero palette to maintain.
  • The ASCII logo is monospace 1-bit art. It is native to this look; in the old navy/yellow chrome it would fight.

Tokens

--ink2 #050505
ground, titlebars
--pane #0d0d0d
window bodies
--paper #f4f4f4
borders, text, NOW block
--grey #8c8c8c
deck frame, done rows

Type

  • Silkscreen (OFL, self-host): titlebars, labels, ticker, LIVE badge. Pixel, 2 weights, legible at 18px on 1080p.
  • Public Sans 800: segment titles, clock, overlay countdown. The "large clean sans" the spec demands.
  • IBM Plex Mono: times, countdown, ASCII logo. Tabular by nature.

The two asks

1. Brand bar on top

New 64px grid row brand above the windows. Left: favicon mark + "CODE CLUB RDU" wordmark + event tag. Right: venue line + blinking LIVE chip. Costs 84px of height; NOW row shrinks 360 → 320px, which still holds a 16:9 deck at 1080 wide. The bar is static per schedule, filled from schedule.event and schedule.place, so it needs no tick handling.

2. ASCII logo instead of NO SIGNAL

Source: ~/Documents/notes/meetup/seventh-event/slides.html, the pre.ascii-art block (114 cols × 10 rows). At 15.4px Plex Mono it is ~1060px wide, fits the deck box with margin. Used in two places: NOW deck host when no deck file exists for the segment (S4's missing-file branch), and the before/idle/after overlay above the countdown. A blinking cursor + "RALEIGH · DURHAM · CHAPEL HILL" under it replaces the "no signal" idea with an idle screen that still says who we are. Store it once in src/lib/live/logo.ts as a template string, render into a <pre>; no image.

Per-window notes

  • Window shell: 3px paper border, 8px hard shadow, titlebar with horizontal stripes (System 7) and two square buttons. Keep .win / .win-title / .win-title-buttons selectors per the S2 handoff.
  • AGENDA: done = 35% + strikethrough; now = inverted block with ▶; next = dashed outline. Three states readable without colour.
  • CLOCK: time in Public Sans 800, countdown in mono. Drop the yellow; "LEFT" becomes a Silkscreen micro-label.
  • TICKER: inverted (paper bg, ink text) so the bottom edge anchors the composition. Fixed "AGENDA" tab on the left, ▶ NOW item inverted back to ink. 60s loop unchanged.
  • INFO: QR in a paper frame (already white, so it scans). Micro-labels in Silkscreen.
  • Overlay: not a bare centered text block. One big window frame with titlebar, logo, countdown. After-phase "running over" keeps the blink but as an inverted chip.
  • Texture: scanlines via ::before repeating-gradient, grain via inline SVG feTurbulence data URI animated in 4 steps, vignette via ::after. All on .canvas so they scale with it. Under prefers-reduced-motion (unless ?motion=1): grain and roll bar freeze, scanlines stay.

Guardrails

  • Scanlines at 28% cut perceived brightness; verified body text stays ≥ 27px, titles 18px pixel. Test on the actual TV, scanline opacity is the first dial to turn down.
  • Grain is a 220px tile at 13% opacity; on a weak AirPlay laptop, drop the animation and keep it static.
  • reveal.js decks sit inside the deck frame untouched; scanlines overlay them too. If a deck has photos, that is the look.
  • Silkscreen has no lowercase-friendly glyphs at small size; never use it for body copy. Spec's "body = clean sans" holds.
